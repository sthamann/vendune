# Current blue Veyndo browser captures — 14 October 2026

These JPEGs are direct, unmodified Chrome viewport captures of the existing
frontend and Rust runtime. The isolated `scripts/grid_directory.py` fixture
creates synthetic shops, products, customers and simulated orders, then removes
its disposable database on shutdown. No real customer data or provider charge
is involved. The running frontend is based on the checked blue `f2aa173` tree.

- `agentic-orders.jpg`: natural-language request, read-only proposed customer
  filter and explicit review before applying. The model response comes from the
  existing deterministic loopback fixture; this is not a paid-model quality test.
- `app-studio.jpg`: the real Product advisor pattern opened in Visual App Studio,
  private draft, shared manifest, form designer and sandbox selection. Preview
  sample rows are labeled; a saved draft is not a production release.
- `connected-knowledge.jpg`: current product facts and provenance-labeled
  curated catalogue relationships. They are not learned customer behavior.
- `fashion-storefront.jpg`: the shipped fictional Nord Atelier collection with
  its existing generated product photographs. No new images were generated.

`manifest.json` records sizes and checksums. Historical showcase videos retain
their own original capture dates and boundaries; updated screenshots do not
make those recordings new.
