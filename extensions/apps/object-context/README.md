# Object context example

This declarative app extends products, customers, orders and companies with one
private, revisioned record per object. Its Manifest owns the four example models,
EN/DE/FR/ES labels, actions and ontology selections. No files are installed into
Core directories; no app-specific SQL table or index is created.

Install and test through the existing native app consent/preview/release paths.
Read the [shared extension guide](../../../docs/app-core-extensions.md) for current
rights, indexed filters, native UI, MCP, operational data boundaries and limits.
This example does not change native prices, order states or financial authority.
